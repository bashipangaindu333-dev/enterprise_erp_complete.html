# Enterprise Cloud ERP System

A complete, single-file Enterprise Resource Planning (ERP) web application built with HTML, CSS, and JavaScript.

## Features
- Business Management Dashboard
- Charts & Analytics (Chart.js)
- Dark / Light Mode
- Fully self-contained — no build tools needed

## How to Run
Simply open `enterprise_erp_complete.html` in any modern browser.
